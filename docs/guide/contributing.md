# Участие в проекте

## Issues

Ошибки и предложения — в [issues](https://github.com/mslab-tech/remnawave-admin/issues). Что полезно приложить к сообщению об ошибке:

- версию панели (карточка на дашборде) и версию агента, если дело в ноде
- кусок логов вокруг проблемы
- что уже пробовали

## Pull request

```bash
git checkout -b feature/название
# правки
git commit
git push origin feature/название
```

Дальше — pull request в репозиторий. Полезно, чтобы изменение приезжало с тестом: он заодно объясняет, что именно чинилось.

Отдельное Contributor License Agreement и подпись через бота не используются. Вклад принимается под основной лицензией репозитория.

## Правки документации

Документация ведётся только на русском в Markdown-файлах каталога `docs/` и читается прямо на GitHub. Для ссылок между страницами используйте относительные пути.
