# Документация Remnawave Admin

Документация хранится в русских Markdown-файлах и читается прямо на GitHub, отдельный сайт не используется.

- [Требования](guide/requirements.md) и [установка](guide/installation.md) — первоначальная настройка.
- [Обновление](guide/upgrade.md) и [устранение неисправностей](guide/troubleshooting.md) — эксплуатация.
- [Node Agent](guide/node-agent.md) — установка и настройка агента на нодах.
- [Обзор возможностей](guide/overview.md) — панель, бот, интеграции и мониторинг.
- [Внешний API](reference/api.md) и [переменные окружения](reference/env.md) — справочники для настройки и интеграций.
- [Заметки релизов](releases/index.md) — изменения версий и ручные шаги обновления.
- `grafana/` и `fail2ban/` — готовые конфигурации для импорта и установки.

Интерфейс панели доступен на русском и английском, документация ведётся только на русском.

Правки документации присылайте через pull request. Ссылки между файлами должны быть относительными, чтобы работать на GitHub.
